# 时光校友圈（AlumniCircle）

## 📘 项目简介

**时光校友圈** 源自曾经的 APP 项目 **啦特** ( https://latter.cn )。  
啦特最初是一款界面风格类似 Twitter 的英文交流社区，但在寻找种子用户的过程中发现核心需求并不真实，因此项目方向被判断为伪需求。

## 🛠️ 技术栈
- **服务端**：Spring Boot + MySQL（暂不开源）
- **客户端**：Flutter + SQLite
- **架构特点**：轻量、可扩展、支持全球用户
- **定位**：开源可再利用的校友社区基础框架
